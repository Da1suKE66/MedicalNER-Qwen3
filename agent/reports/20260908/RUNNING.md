## 自动评测已接通

三轮 SFT 结束后逐个评测每 epoch checkpoint：完整内部 tuning 图生成 → 仅按 tuning F0.5 等选 checkpoint → 完整148条历史回归的固定预测实体与标准实体评测。规则关闭/逐项开启的删 TP/FP 数同时输出。最大输出预算16000 tokens，所有截断和非法输出保留计数。

固定实体和标准实体评测都不等于真实更新后 entity→relation 联跑；后者、剩余去项消融、RL、重复 seed/置信区间仍有待完成。DPO/GRPO 环境和接口已检查，但没有把它们记为完成了正式 RL 训练。

## 工程检查发现了什么

- 全部185项软件测试通过。
- 真实 SFT 前后向可执行，43,646,976个可训练参数均为 LoRA。保存/重载输出一致性检查通过。
- 实际 chat 模板后的 G0 最长5,032 tokens、均值3,146.16；G6最长3,234、均值2,058.22。均未超过6,144训练上限，没有静默左截断。
- 两步工程 checkpoint 在两个合成样例上，裸 prompt 的3个批全部触及512上限且无法完成JSON；固定同一 checkpoint，仅使用 Qwen3 非 thinking chat 模板后，3个批均不再截断，总输出293 tokens。
- 模板修改后仍存在1条错误边。这说明消除长推理不等于修复语义错误。两个合成例子的分数不能当作整体医学准确率，更不能当作完整训练的提升。

训练、SFT偏好/RL和推理现共用同一个非 thinking renderer。这是所有正式G组共有的安全修复，不作为其中一组独有的收益。[Qwen 官方文档](https://huggingface.co/Qwen/Qwen3-8B#switching-between-thinking-and-non-thinking-mode)说明了关闭 thinking 的硬开关。
