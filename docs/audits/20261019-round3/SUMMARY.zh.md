# 一小时续跑的完整结果与DPO数据

第一份新模型结果在北京时间2026-10-19 20:39交付，早于20:49的要求。关系标签加权SFT完整训练1000行并完成130条评测，但自由文本关系F1仅从47.8873%变为47.9920%，不足以认为这个方向已经获得可靠提升；保留原选定pipeline。

全部130条都评测，没有剔除失败样本。主表单列69条自由文本，以免61条确定性结构化处理抬高模型表现。合并130条关系F1为51.6129%，结构化部分F1仍75.4967%；后者不是大模型新训练的效果。实体输出完全复用基线，自由文本实体F1仍68.7822%。这些结果尚未达到70–80%的关系目标。

独立重算使用原始gold分母：自由文本648个实体、573条关系。关系以规范化后的带类型首尾实体及有向关系标签做集合精确比较，证据不参与关系身份，但必须通过规则检查。P=TP/(TP+FP)，R=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)。Precision不冒充含TN的准确率；不加模糊匹配分数。此130条是反复使用过的tune，不是独立盲测；标注来自银标，FP并非全部经人工确认的医学错误。

本次从原SFT父模型继续1epoch，LR2e-5、rank16、batch1/accum8、125次更新；关系标签token权重4，其他目标含EOS权重1，prompt和padding不计损失。完整1000行各出现一次；目标399973 token，其中标签27752 token、EOS1000个，无训练截断。独立CPU读取权重确认实际参数变化、有限值及父模型身份。旧父manifest的真实LR为1e-4，不能把路径缩写读成1e-5。额外epoch、学习率和损失权重同时变化，缺少匹配的不加权续训对照，不能单独归因为标签加权。

125个实际关系提示、实体表、输入和评分实现与基线一致。结果出现11个新TP、10个丢失TP、37个消失FP、38个新FP，最终只净增1TP和1FP；因此不能用某几个改善例子概括整体。262个FN仍缺至少一端实体；双方实体均可用的FN从73变为72。前者说明只改关系模型无法绕过上游实体缺失，但不能据此把其余语义错误都归给上游。

关系失败窗口从18变成21，截断从0变成1。新模型124/125次生成观察到EOS，另一次用完4096 token仍无EOS。两条新失败是4列definition记录，关系协议要求6列；它们有EOS，不能称为JSON错误或截断。失败次数与graph FP/FN不是同一指标，不能直接相加或把全部TP变化归因于失败。具体问题文本仅在私有本地分析中保存。

本轮实际向DeepSeek Flash发送31个既有TRAIN来源，成功调用62次，合计128659 token。最初5/31通过主要因为审查提示歧义：21条仅因模型拒绝返回刻意错误的负例而失败，不代表训练银标错误率。改为明确“rejected本来刻意为假”的A/B审核后，26条复审中25条通过；没有静默把旧null改为通过。完整chosen再经本地逐条复核，最终构建24对，隔离7对：13对core→argues_against、8对argues_against→core、3对子类方向反转。完整176条chosen关系保持不变，每对只改一条；未标注不当负例，不输出none，不使用数字候选协议。

24对是现有TRAIN上的偏好样例，不是新增24篇独立SFT文档，也不是人工医学gold。最长3273/4096 token，chosen11155、rejected11150 token（均含EOS）；训练器本地及服务器CPU数据、原父模型检查通过。7个待查候选涉及否定/限定词边界、相邻子类证据、核心症状支持范围、旧本体释义和API返回自相矛盾；不把它们全部认定为错误标注，不改旧训练数据或评测gold。
